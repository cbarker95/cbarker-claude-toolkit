# CTA Optimization

Call-to-action copy, placement, friction reduction, and form optimization for B2B SaaS pages. The CTA is the moment of conversion — everything else on the page exists to get the visitor here.

---

## CTA Copy Formulas

Great CTA copy describes the outcome, not the action. "Submit" describes what the visitor does. "Start building faster" describes what they get.

### Formula 1: Action + Outcome
```
"Start shipping faster"
"Deploy your first app"
"Build your dashboard"
```

### Formula 2: Action + Timeframe
```
"Get started in 2 minutes"
"Deploy in 5 minutes"
"Set up your workspace now"
```

### Formula 3: Claim the Benefit
```
"Start free"
"Try it free"
"Get instant access"
```

### Formula 4: Specific Next Step
```
"Create your first project"
"See your metrics live"
"Connect your first integration"
```

### Weak CTAs to Avoid
| Weak | Why It Fails | Better |
|------|-------------|--------|
| "Learn More" | No commitment, no outcome | "See how it works" |
| "Get Started" | Vague — started with what? | "Start your free workspace" |
| "Submit" | Transactional, not outcome-driven | "Get my results" |
| "Sign Up" | Focuses on friction, not benefit | "Start free — no credit card" |
| "Request a Demo" | High friction for self-serve | "Try it free" (primary) + "Watch demo" (secondary) |
| "Contact Us" | Ambiguous, high commitment | "Talk to an expert" or "Get a custom quote" |

## Primary + Secondary CTA Pairing

Every hero should have two CTAs: primary for the ready buyer, secondary for the curious evaluator.

### Pairing Patterns

**Self-Serve Product:**
```
Primary:   [Start free]           — For those ready to try
Secondary: [Watch 2-min demo]     — For those still evaluating
```

**Enterprise Product:**
```
Primary:   [Start free trial]     — For hands-on evaluators
Secondary: [Talk to sales]        — For buyers who need a conversation
```

**Product-Led Growth:**
```
Primary:   [Start building]       — For developers ready to go
Secondary: [Read the docs]        — For developers who research first
```

**Launch / Campaign:**
```
Primary:   [Get early access]     — For eager adopters
Secondary: [See what's coming]    — For the curious
```

### Visual Hierarchy
- Primary CTA: Filled button, high contrast, prominent size
- Secondary CTA: Ghost/outline button or text link, same line as primary
- Primary always comes first (left or top)

## Friction Reducers

Friction reducers are short text near the CTA that address the visitor's hesitation. They answer: "What's the catch?"

### Placement
```
┌─────────────────────┐
│  [Start free]       │   ← Primary CTA
│  [Watch demo]       │   ← Secondary CTA
│                     │
│  No credit card     │   ← Friction reducer
│  required           │
└─────────────────────┘
```

### Effective Friction Reducers
| Hesitation | Friction Reducer |
|-----------|-----------------|
| "Will it cost me?" | "Free forever for up to 5 users" |
| "Do I need a credit card?" | "No credit card required" |
| "How long does setup take?" | "Set up in under 2 minutes" |
| "Can I leave if I don't like it?" | "Cancel anytime, no questions asked" |
| "Is my data safe?" | "SOC 2 certified. Your data stays yours." |
| "Do I have to talk to sales?" | "No sales calls. Start on your own." |
| "Is there a contract?" | "Month-to-month. No annual commitment required." |

### Rules
- Place within 8px of the CTA button — it must be visually connected
- Keep it to one line (two maximum)
- Address the #1 objection for your product category
- Don't use more than 2 friction reducers per CTA instance

## CTA Placement Patterns

### Minimum Viable CTA Strategy (3 Placements)
```
1. Hero          — Primary + Secondary + friction reducer
2. Mid-page      — After features or social proof section
3. Page bottom   — Final CTA with closing argument
```

### Comprehensive CTA Strategy (5+ Placements)
```
1. Nav bar       — Persistent CTA in top-right
2. Hero          — Primary + Secondary + friction reducer
3. After logos   — For visitors convinced by social proof
4. After features — For visitors convinced by capabilities
5. After proof   — For visitors convinced by testimonials
6. Sticky bar    — Appears after scrolling past hero
7. Page bottom   — Final CTA with urgency/closing argument
```

### Sticky CTA Bar
Appears after the hero scrolls out of view. Keeps the conversion action always accessible.
```
┌──────────────────────────────────────────────────┐
│  [Logo]     The deploy platform for modern teams  [Start free →]  │
└──────────────────────────────────────────────────┘
```

## Form Optimization

### Field Reduction
Every form field you add reduces conversions. For SaaS sign-up:

| Fields | Typical Conversion Impact |
|--------|--------------------------|
| Email only | Highest conversion |
| Email + name | Slight drop |
| Email + name + company | Noticeable drop |
| Email + name + company + phone + role | Significant drop |

**Rule:** Only collect what you need for the immediate next step. You can collect more during onboarding.

### Progressive Disclosure
```
Step 1: [Email]  [Start free →]          — Lowest friction
Step 2: [Name] [Company] [Continue →]     — After they've committed
Step 3: [Use case] [Team size] [Go →]     — During onboarding
```

### Sign-Up Patterns
**Lowest friction (product-led):**
```
[Work email]  [Start free →]
Sign up with Google | Sign up with GitHub
```

**Medium friction (B2B with qualification):**
```
[Work email]  [Company]  [Start free trial →]
```

**Higher friction (enterprise, justified):**
```
[Name] [Work email] [Company] [Team size ▾]  [Get started →]
```

## Pricing Page CTA Strategies

### Tier Anchoring
Visually emphasize the tier you want most people to choose:
- "Most Popular" badge on the recommended tier
- Slightly larger card or elevated visual treatment
- Different background color or border
- Pre-selected toggle state

### Tier CTA Differentiation
| Tier | CTA Copy | Notes |
|------|----------|-------|
| Free | "Get started" | Low commitment, instant access |
| Pro / Team | "Start free trial" | Emphasize the trial, not the price |
| Enterprise | "Talk to sales" or "Get a custom plan" | Expected for enterprise |

### Annual vs. Monthly Toggle
```
[Monthly]  [Annual — Save 20%]
```
- Default to annual (higher LTV)
- Show savings prominently ("Save $240/year")
- Badge the annual option: "Most Popular" or "Best Value"

### Money-Back Guarantee
For paid tiers without a free trial:
```
"30-day money-back guarantee. Try it risk-free."
```
Place directly below the CTA button as a friction reducer.
